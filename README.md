# 극플드라이브 클라이언트 (32비트 Windows 10 공용 PC용)

`gcflarchive.co.kr/share`의 극플드라이브를 학교 공용 PC에서 PIN 하나로 쓰게 해 주는 프로그램입니다.
**학번과 PIN 4자리**로 로그인해 올려 둔 파일을 출력하거나 지울 수 있습니다. PIN은 `gcflarchive.co.kr/share` 에서 확인·변경합니다. ("비밀번호를 잊으셨나요?"는 그 웹 로그인에만 있습니다.)

> **아직 Windows 실기에서 실행해 보지 못했습니다.** 개발 환경이 Linux라서, 화면(HTML)은 브라우저로,
> 코어 로직은 단위 테스트로 확인했고 Windows 전용 부분(창·서비스·프린터 감시)은 32비트로 컴파일까지만 확인했습니다.
> 아래 「Windows 첫 점검 목록」을 한 대에서 먼저 돌려 본 뒤 배포하세요.

## 동작

| 화면 | 설명 |
|---|---|
| 로그인 | "학번으로 로그인. 간편하게 프린트." 학번 + PIN 4자리. |
| 내 파일 | 남은 시간 배지(`6d`·`17h`·`2m 30s`), **출력** / **지우기**, 5분 자동 로그아웃 카운트다운 |
| 대기 화면 | 3분 동안 아무도 PC를 쓰지 않으면 PIN 화면이 전체화면으로 올라옵니다(화면보호기처럼). 아래쪽에 "허락을 받아 설치한 소프트웨어이니 임의로 닫거나 지우지 말아 주세요" 안내가 함께 나옵니다. 왼쪽 아래 **바탕화면으로 나가기**을 누르면 바탕화면으로 빠지고, 10분 동안은 다시 올라오지 않습니다 |

- 출력: PDF·그림·글은 그대로, **한글(HWP/HWPX)** 은 사이트의 rhwp 뷰어로 그려서, **DOCX·PPTX·XLSX 등**은 서버가 PDF로 바꿔 보내 줍니다. 프린터 선택은 Windows 인쇄 창에서 합니다.
- 파일은 PC에 저장되지 않습니다. 브라우저 프로필은 실행마다 새로 만들고 끝나면 지웁니다. PIN은 프로그램(Go)만 메모리에 들고 있고 화면(HTML)은 모릅니다.
- 첫 출력부터 5분 뒤 서버에서 파일이 지워집니다(서버 규칙).

## 종이 7장 제한

어떤 프로그램에서 출력하든 한 작업이 종이 7장을 넘으면 보호 서비스가 **작업을 취소하고 화면에 경고**를 띄웁니다. 경고는 극플드라이브 창이 KRDS 스타일 대화상자로 보여 줍니다(최소화돼 있으면 잠깐 올라왔다가 확인 후 다시 내려갑니다). 창이 8초 안에 받아 가지 못하면 Windows 기본 메시지 상자로 대신 알립니다.

- 서비스가 Windows 프린터 대기열을 0.4초마다 감시합니다. 새 작업은 스풀이 끝날 때까지 잠시 멈춰 두었다가 `쪽수 × 매수`(양면이면 쪽수의 절반)를 계산해 7장 이하면 풀어 줍니다.
- 극플드라이브 화면에서는 인쇄 창을 열기 전에 먼저 안내합니다(8~14쪽: 양면일 때만 가능하다는 경고, 15쪽 이상: 차단).
- **한계**: 장수는 추정치입니다(N-up 같은 드라이버 설정은 반영되지 않음). 쪽수를 알려 주지 않는 RAW 방식 작업은 측정할 수 없어 통과됩니다. 한 작업 기준이라 2장씩 여러 번 나눠 출력하는 것은 막지 못합니다. 정확한 제한이 필요하면 프린터 자체의 매수 제한 기능을 함께 쓰세요.
- **한도는 온라인으로 조정합니다.** 사서 선생님이 `gcflarchive.co.kr/drive-admin` 에서 바꾸면(기본 7장, 1~50) 각 PC가 5분마다 읽어 가며 마지막 값을 PC에 저장해 두므로 오프라인으로 켜져도 유지됩니다.
  - 처음 접속하면 이 페이지 전용 비밀번호(8자 이상, 계정 아님)를 정합니다. **학교 안에서만** 정할 수 있고, 정하기 전에는 학교 IP의 누구나 정할 수 있으니 서버 배포 직후 바로 정해 두세요.
  - 비밀번호를 잃으면 사이트 관리자가 `POST /api/drive-admin/reset` 으로 지우고 다시 정합니다.

## 보호 (학생이 닫거나 지우지 못하게)

공용 PC가 **관리자 계정을 함께 쓰는 환경**을 전제로, 한 겹으로 막지 않고 여러 겹으로 겹칩니다.

1. **창 닫기는 비밀번호로만** — 닫기 버튼, Alt+F4, 작업 표시줄 "창 닫기", 일반 `taskkill`의 닫기 요청은 닫는 대신 **관리자 비밀번호 창**을 엽니다. 맞으면 종료(10분간 보호 해제) 또는 제거를 고를 수 있고, 틀리면 닫히지 않습니다. 최소화는 자유롭게 됩니다.
2. **자동 재실행** — SYSTEM 권한 서비스(`GCFLDriveGuard`)가 부팅 때부터 돌며, 로그인한 사용자 세션에 창을 띄우고 닫히면 1.5초 안에 다시 띄웁니다. 시작프로그램(Run 키)에도 같이 등록합니다.
3. **서비스 정지·삭제 불가** — 서비스 개체와 레지스트리 키의 권한을 SYSTEM 전용으로 잠가, 관리자도 `sc stop/delete/config`와 `Start=4` 변경이 거부됩니다. 서비스는 정지 요청 자체를 받지 않습니다. 비정상 종료 시 SCM이 즉시 재시작하고, 안전 모드에서도 돕니다.
4. **파일 보호** — 설치 폴더는 SYSTEM만 쓰기 가능(관리자도 읽기·실행만)이고, 소유자도 SYSTEM입니다. 지워지거나 바뀌면 서비스가 백업본에서 되살립니다. 프로그램 목록(앱 및 기능)에는 나타나지 않습니다.
5. **프로세스 보호** — 창 프로세스는 종료 권한을 막아 둡니다. 작업 관리자와 레지스트리 편집기는 정책으로 막습니다.
6. **제거는 서비스만** — 제거는 관리자 비밀번호를 서비스가 확인한 뒤 서비스 스스로 합니다. 틀리면 1초씩 지연되고 5번 틀리면 5분 잠깁니다.

**한계**: 이 PC의 관리자 권한이 있고 방법을 아는 사람(소유권 가져오기, SYSTEM으로 실행, 다른 OS로 부팅, 디스크 분리 등)을 끝까지 막을 수는 없습니다. 목표는 학생이 실수나 장난으로 1분 안에 못 끄게 하는 것입니다. 근본적으로 막으려면 학생 계정을 **표준 사용자**로 바꾸세요(그러면 위 보호가 훨씬 단단해집니다).

## 설치와 관리

1. `./build.sh` → `dist/` 에 `gcfldrive.exe`, `install.cmd`, `uninstall.cmd`
2. WebView2 런타임이 없는 PC가 있으면 `MicrosoftEdgeWebView2RuntimeInstallerX86.exe`(Evergreen 독립 실행형 x86)를 `dist/` 에 같이 넣습니다.
3. 각 PC에서 `install.cmd` 실행 → 끝. 관리자 비밀번호는 모든 PC에 같은 기본값이 들어가며(소스에는 해시만 있음), PC마다 다르게 하려면 `gcfldrive.exe install --set-password`로 설치하세요. 다음 로그인부터 창이 자동으로 뜹니다.
4. **종료·제거**: 창을 닫으려 하거나(Alt+F4) "Powered by" 로고를 4초 안에 7번 누르거나 Ctrl+Shift+F12 → 관리자 비밀번호 →
   - *프로그램 종료(10분간 보호 해제)*: 창이 닫히고 작업 관리자·레지스트리 편집기·출력 제한이 10분간 풀립니다. 끝나면 자동으로 다시 보호합니다. 일찍 켜려면 `gcfldrive.exe resume`.
   - *프로그램 제거*: 서비스·파일·정책을 모두 지웁니다. (명령줄은 `uninstall.cmd`)
5. 업데이트는 제거 후 다시 설치합니다.

## Windows 첫 점검 목록

- [ ] `install.cmd` → 3초 뒤 창이 자동으로 뜨는가
- [ ] 로그아웃/재부팅 후 다시 로그인하면 창이 뜨는가
- [ ] 닫기 버튼·Alt+F4·작업 표시줄 닫기가 먹지 않는가, 작업 관리자가 막혀 있는가
- [ ] 관리자 cmd에서 `sc stop GCFLDriveGuard`, `taskkill /f /im gcfldrive.exe`가 거부되는가
- [ ] 창 프로세스를 어떻게든 끝내도 2초 안에 다시 뜨는가
- [ ] 학번+PIN 로그인 → 목록 → 출력(PDF·DOCX·HWP) → 5분 카운트다운 → 지우기
- [ ] 사서 선생님 페이지에서 장수를 바꾸면 5분 안에 반영되는가
- [ ] 8장 이상 PDF를 **다른 프로그램(메모장·Edge)** 에서 인쇄하면 취소되고 경고가 뜨는가
- [ ] 3분 방치 후 전체화면 → 로고 7번 클릭 → 비밀번호 → 보호 풀기/제거
- [ ] 125% 배율에서 창 크기와 글자가 어색하지 않은가

## 개발

```
go test ./internal/...            # 코어(API·세션·비밀번호·7장 계산·로컬 서버)
go run ./cmd/uipreview            # 출력되는 주소를 브라우저로 열면 화면을 볼 수 있습니다 
GOOS=windows GOARCH=386 go vet .  # Windows 전용 코드 컴파일 확인
```

서버(`archive_dev`)의 `/api/share/drive/*`, `/api/share/settings` 를 씁니다. 서버 주소는 환경변수 `GCFLDRIVE_SERVER`로 바꿀 수 있습니다.

디자인은 KRDS 토큰(`--primary #256EF4`, 회색 스케일, 위험 `#DE3412`)과 Pretendard를 쓰고, 제공된 화면과 같게 맞췄습니다.
라이선스: Pretendard(OFL), PDF.js(Apache-2.0).
